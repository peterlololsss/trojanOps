Reviewers check the event count before the budget. Flag requests that split one event into two.

Internal notes for USG reviewers and admins. Demo text.

## Order of review

1. Event count: a club that has already held 4 funded events this semester cannot be funded for a fifth.
2. Annual cap: add the request to the club's funded total for the year and compare it with $8,000.
3. Vendor lead time: 6 instructional weeks between the request and the event for approved vendors.
4. Deadline: Wednesday at 11:59 PM PT.

## What to flag

- Two requests for the same date and venue under different event names.
- A vendor quote dated after the request was submitted.
- A request that reaches the annual cap exactly; ask the club for its line items.

Write the reason for every flag in the review, in one sentence the club can act on.
